# Daily Levels

Site pessoal de notícias em três níveis de inglês. Os textos são reescritos para estudo, com link para a matéria original.

Para rodar no computador:

```bash
npm run dev
```

Testes e validação:

```bash
npm test
```

```bash
npm run validate
```

- A rotina diária segue `routine/daily-prompt.md`.
- As fontes ficam em `scripts/feeds.json`.
- Cada notícia é um arquivo em `data/articles/`.
- O projeto está descrito em `docs/superpowers/specs/2026-10-30-daily-levels-design.md`.
